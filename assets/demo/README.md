# 演示截图（documents only，不含真实数据）

这里出的是给 GitHub README / 技能市场用的产品截图。**图里没有一个真实数字。**

做法是「从数据源头造假」，不是截真表再涂改：`make_ledger.py` 生成一份符合
`collect.py` 解析口径的合成账本（假 `workbuddy.db` + 假 `projects/**/*.jsonl`），
再用**未经改动的** `report.py` 渲染，最后无头 Chrome 截图裁切。

涂改路线的坏处：KPI 加总对不上明细、结论句里的百分比和表格矛盾，一眼假。
合成账本走的是同一条渲染链路，所以排版、图表、结论生成逻辑都是产品真实行为。

## 复现要点

账本里合成数据的截止日**写死**在 `make_ledger.py` 的 `END`（2026-10-25），
而 `report.py` 的基准日默认取**运行当天**。两者不齐时，「近 7 日 / 近 30 日」的
窗口会跟着漂——同样的账本、不同天跑，会得到不同的小计。

要逐像素复现仓库里那三张图，渲染时必须显式钉住基准日：
`--anchor 2026-10-25`。

顺便说明这个设计的好处：图片里的 `3,887.49 积分 / 29.13M token` 与任何人的
真实账单无关，任何人 clone 下来跑一遍都能得到同一组数——**可复现，才可审计**。

## 重新生成

```bash
cd assets/demo
python make_ledger.py --clean                      # 合成账本（固定随机种子，可复现）
python ../../scripts/report.py \
    --config-dir demo-ledger --anchor 2026-10-25 --out out --format all
# 2 倍像素整页截图（1440×5800 视口 → 2880×11600，高度取「不小于页面高」即可）
chrome --headless=new --disable-gpu --hide-scrollbars \
       --force-device-scale-factor=2 --window-size=1440,5800 \
       --screenshot=raw-2x.png --virtual-time-budget=4000 \
       file:///<abs>/out/index.html
python crop.py                                     # 按版面边界裁三版，顺带出卡片版
```

## 三版的裁切边界

版面坐标是量出来的（用注入脚本读 `h2[id^=s-]` 的 `getBoundingClientRect()` 与相邻
面板的 `bottom`，1440 视口下 clientWidth=1422），不是目测：

| 章节 | 1x y 范围 |
|---|---|
| 导航 + 标题 + 五张 KPI 卡 | 0 – 437 |
| 环比表 | 490 – 895 |
| 结论区 | 947 – 1274 |
| 每日趋势 | 1326 – 1702 |
| 活跃日历（含两张子卡） | 1754 – 2185 |
| 官方价预估 | 2237 – 2775 |
| 按模型 | 2827 – 3174 |

- **A 概览**：`0 – 905`，含导航 / 标题 / 五档 KPI / 完整环比表 → 2880×1810
- **B 洞察**：`940 – 2225`，含结论区 / 每日趋势 / 活跃日历 → 2880×2570
- **C 定价**：`2200 – 3200`，含官方价预估 / 按模型 → 2880×2000

注意 `--window-size` 的高度会影响 `clientHeight`（等同视口时才一致），但**不影响纵向
坐标**——只要宽度一致，各章节的 y 就是稳定的，所以 1x 量出的边界可以直接 ×2 用到 2x 图上。

每个方案出两份：原始截图（`shot-*.png`）与卡片版（`shot-*-card.png`，圆角 22px +
半透中灰描边、圆角外透明）。卡片版是为 GitHub README 准备的：深色截图直接铺在
白底页面上是一整块直角墨，加圆角与描边后才有「贴在页面上的一张图」的观感。
描边用半透中灰（`150,162,180,170`）而不是纯白或纯黑，白底读作浅灰、深底读作
亮灰，一份文件两种主题都能收边。

## 合成数据的设定

- 时间跨度 08-20 ~ 10-25（起点必须早于近 30 日的上期起点 08-27，否则报表会给这一档
  打星号「上期起始日早于本机最早记录日」）
- 12 个会话 / 3 个工作区 / 3 个已定价模型，1,698 条请求
- 周末降到 0.45、国庆 10-01~10-08 降到 0.12 —— 趋势图需要有起伏，平直的一条没人信
- 工作区路径一律 `/home/dev/workspace/*`，不出现任何真实用户名

`--config-dir demo-ledger` 用相对路径是刻意的：页眉「数据源」那行会原样显示传入的
路径字符串，绝对路径会把本机的盘符和目录带进图里。
